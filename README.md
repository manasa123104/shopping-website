# FIELD

FIELD is a family clothing shop for denim, tees, fleece, and everyday layers. Browse departments, filter the catalog, add a size to your bag, and place a demo order.

Open the shop: [http://localhost:5173](http://localhost:5173)

## Run it

```bash
npm install
npm run dev
```

If port 5173 is already in use, Vite prints a different local URL. Use that one. `npm run build` writes a production build to `dist`, and `npm run preview` serves that build.

## Shop

- Departments: Women, Men, Girls, Boys, Baby, Toddler, and Sale
- Filters by type, plus sort by featured, new, or price
- Search across names, colors, and descriptions
- Product pages with color, size, and quantity
- Bag saved in this browser, with free shipping at $75 and $8 below that
- Demo checkout. Nothing is charged, and no email is sent

Shipping, returns, and the size guide are on the Help page.
